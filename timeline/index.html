1.2 STM32 简介 P2 [1-2]

STM32 是 ST 公司基于 ARM Cortex-M 内核的 32 位单片机系列。

  • 芯片型号：STM32F103C8T6 — F1系列、103型、C=48引脚、8=64KB Flash、T=LQFP封装、6=-40~85°C
  • 内核：Cortex-M3，32位，主频72MHz
  • 片上资源：GPIO、USART、I2C、SPI、TIM、ADC、DMA、RTC、看门狗等
  • 最小系统：电源、复位、时钟（8MHz外部晶振）、BOOT启动配置

GPIO 输入输出

GPIO 结构与 8 种模式，LED、蜂鸣器、按键、光敏传感器
3.1 GPIO 输出 P5 [3-1]

GPIO 通用输入输出端口，8 种工作模式：

  • 推挽输出：P-MOS+N-MOS 都工作，高低电平都有强驱动（LED、蜂鸣器）
  • 开漏输出：只有 N-MOS，高电平为高阻态，需外部上拉（I2C）
  • 复用推挽/开漏：由外设控制引脚（TX、PWM、硬件I2C）
  • 上拉/下拉/浮空输入：按键、RX 等
  • 模拟输入：ADC 采集
推挽输出：写1→P-MOS导通→强高电平；写0→N-MOS导通→强低电平
GPIO 初始化（推挽输出）
/*第一步：开启时钟*/
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

/*第二步：初始化GPIO*/
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;      //推挽输出
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;            //PA0
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &GPIO_InitStructure);

/*操作引脚*/
GPIO_SetBits(GPIOA, GPIO_Pin_0);    //置高电平
GPIO_ResetBits(GPIOA, GPIO_Pin_0);  //置低电平

GPIO 输入模式：上拉输入、下拉输入、浮空输入。通过 GPIO_ReadInputDataBit 读取引脚电平。

  • 上拉输入：默认高电平，按下按键接地读到低电平

3.4 按键控制 LED & 光敏传感器控制蜂鸣器 P8 [3-4]

按键扫描（带软件消抖）和光敏传感器数字量读取。

消抖流程：检测电平变化 → Delay_ms(20) → 再判断 → 等待松手 → Delay_ms(20)
  • 机械按键按下/释放瞬间有 5~10ms 抖动，必须消抖
  • 此扫描方式是阻塞式，按住不放时函数卡住
  • 光敏传感器：比较器输出数字量，与按键原理相同
按键扫描（带消抖）
uint8_t Key_GetNum(void)
{
    uint8_t KeyNum = 0;
    if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)  //1.检测按下
    {
        Delay_ms(20);                                    //2.延时消抖
        while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0); //3.等待松手
        Delay_ms(20);                                    //4.松手消抖
        KeyNum = 1;
    }
    return KeyNum;
}

EXTI 外部中断

中断原理、NVIC 优先级、EXTI 外部中断及实验
5.1 EXTI 外部中断 P11 [5-1]

中断让 CPU 暂停当前任务，优先处理紧急事件。

主程序 → 中断触发 → 保存断点 → 中断服务函数 → 恢复断点 → 继续主程序
  • NVIC 优先级：抢占优先级（可嵌套）+ 响应优先级（排队不可嵌套），分组2：2位抢占+2位响应
  • EXTI 线路：引脚电平变化 → AFIO 选择引脚 → EXTI 边沿检测 → NVIC → 中断服务函数
  • 相同 Pin 号不能同时挂中断（PA0 和 PB0 不能同时用 EXTI0）
进入中断后必须清除中断标志位，否则反复进入中断导致主程序卡死。中断函数名必须与启动文件向量表一致。
EXTI 初始化五步法
/*第一步：开启时钟（GPIO和AFIO都要开）*/
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE);
/*第二步：GPIO上拉输入*/
/*第三步：AFIO选择中断引脚*/
GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource14);
/*第四步：EXTI配置（下降沿触发）*/
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
/*第五步：NVIC配置*/
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
NVIC_InitStructure.NVIC_IRQChannel = EXTI15_10_IRQn;
NVICAFIOEXTI抢占/响应优先级清标志位
5.2 对射式红外传感器计次 & 旋转编码器计次 P12 [5-2]

两个 EXTI 实验：红外传感器挡光触发计数；旋转编码器双 EXTI 判断方向。

  • 红外传感器：PB14 下降沿触发，中断中计数++，可在中断中再次判断电平防抖
  • 旋转编码器：A/B 两相各接一个 EXTI 通道，A 上升沿时读 B 电平判断正反转
正转：A上升沿时B=低 → Count++；反转：A上升沿时B=高 → Count--
红外传感器中断服务函数
void EXTI15_10_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line14) == SET)   //1.判断中断线
    {
        if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_14) == 0)
            CountSensor_Count++;                       //2.计数自增
        EXTI_ClearITPendingBit(EXTI_Line14);         //3.清除标志位
    }
}

定时器 TIM

定时中断、输出比较PWM、输入捕获、编码器接口——STM32 核心外设
6.1 TIM 定时中断（理论） P13 [6-1]

定时器时基单元：PSC 预分频器 + CNT 计数器 + ARR 自动重装器。

CK_PSC(72MHz) → [PSC+1分频] → CK_CNT → [CNT计数] → 达到ARR → 更新事件 → 中断
溢出时间 T = (PSC+1) × (ARR+1) / 72000000 秒
  • PSC=7199, ARR=9999 → T = 7200×10000/72MHz = 1秒
  • APB1 定时器时钟经倍频后为 72MHz（APB1 预分频≠1 时×2）
  • PSC 影子寄存器：写入后等更新事件才生效；ARPE=1 时 ARR 同理
TIM_TimeBaseInit() 末尾会手动产生一次更新事件，开中断前必须先 TIM_ClearFlag()。
PSCCNTARR更新事件影子寄存器
6.2 定时器定时中断 & 定时器外部时钟（代码） P14 [6-2]

定时中断初始化七步法 + 外部时钟模式（ETR 脉冲计数）。

Timer_Init — 定时中断初始化
/*第一步：开启时钟*/

/*第二步：选择内部时钟源*/

/*第三步：配置时基单元*/

TIM_TimeBaseInitStructure.TIM_Prescaler = 7200 - 1;      //PSC → 1秒
TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);
/*第四步：清除更新标志（避免初始化后立即进中断）*/
TIM_ClearFlag(TIM2, TIM_FLAG_Update);
/*第五步：开启更新中断*/
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
/*第六步：NVIC配置*/
/*第七步：启动定时器*/
TIM_Cmd(TIM2, ENABLE);

6.3 TIM 输出比较（理论） P15 [6-3]

输出比较产生 PWM 波形：CNT 与 CCR 比较，决定输出有效/无效电平。

CNT < CCR → 有效电平（高）；CNT ≥ CCR → 无效电平（低）；CNT=ARR → 归零重复
PWM频率 = 72M/(PSC+1)/(ARR+1)；占空比 = CCR/(ARR+1)
  • PWM 模式1：CNT<CCR 有效，CNT≥CCR 无效
  • 引脚必须配置为复用推挽输出（AF_PP）
CCRPWM模式1占空比复用推挽
6.4 PWM 驱动 LED 呼吸灯 & 舵机 & 直流电机 P16 [6-4]

三个 PWM 应用实验。

  • 呼吸灯：PSC=720-1, ARR=100-1 → 1kHz，CCR 0→100→0 渐变
  • 舵机：周期20ms(50Hz)，PSC=720-1, ARR=2000-1，CCR=50~250 对应 -90°~+90°
  • 直流电机：TB6612 驱动，CCR 调转速，方向引脚控制正反转
舵机：0.5ms→-90°(CCR=50)，1.5ms→0°(CCR=150)，2.5ms→+90°(CCR=250)

6.5 TIM 输入捕获（理论） P17 [6-5]

输入捕获测量外部信号频率（测周法）：

上升沿 → 从模式Reset → CNT清零 → 重新计数 → 下一个上升沿 → CCR1锁存N → 频率 = fc/N
  • PSC=72-1 → fc=1MHz，频率 = 1000000/(CCR1+1)
  • 滤波器过滤信号抖动，从模式 Reset 每个上升沿自动清零 CNT
测周法从模式ResetTI1FP1滤波器
6.6 输入捕获测频率 & PWMI 测频率占空比（代码） P18 [6-6]

输入捕获测频率 + PWMI 模式同时测频率和占空比。

  • 通道1直连：上升沿捕获 CCR1 = 周期
  • 通道2间接：下降沿捕获 CCR2 = 高电平时间
频率 = fc/CCR1；占空比 = CCR2/CCR1
输入捕获配置
/*时基：PSC=72-1(fc=1MHz), ARR=65536-1*/
/*输入捕获：通道1，上升沿，直通，滤波器0xF*/
TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
TIM_ICInitStructure.TIM_ICFilter = 0xF;
TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;
TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_DirectTI;
TIM_ICInit(TIM3, &TIM_ICInitStructure);
/*触发源TI1FP1，从模式Reset（上升沿CNT清零）*/
TIM_SelectInputTrigger(TIM3, TIM_TS_TI1FP1);
TIM_SelectSlaveMode(TIM3, TIM_SlaveMode_Reset);

// 获取频率
return 1000000 / (TIM_GetCapture1(TIM3) + 1);
PWMI双通道间接映射CCR1/CCR2
6.7 TIM 编码器接口（理论） P19 [6-7]

硬件自动解析正交编码器方向和位移，无需 CPU 干预。

正转：A上升沿时B=低 → CNT++；反转：A上升沿时B=高 → CNT--
  • TIM_EncoderMode_TI12：两相都计数，4 倍频精度
  • 每隔固定时间读 CNT 增量并清零，即为速度
正交编码TI12模式4倍频硬件自动

ADC 与 DMA

模数转换与无需 CPU 干预的数据自动转运
7.1 ADC 模数转换器（理论） P21 [7-1]

将模拟电压转换为数字量：采样 → 保持 → 量化 → 编码。

  • ADCCLK = 72MHz/6 = 12MHz（最大14MHz）
  • 12 位分辨率：0~3.3V 对应 0~4095
  • 转换时间 = 采样时间 + 12.5 个 ADC 周期（55.5周期采样 ≈ 5.67μs）
  • 上电后需校准：复位校准 → 等待 → 启动校准 → 等待
电压换算：Voltage = ADValue / 4095 × 3.3
12位12MHzEOC校准规则组

8.1 DMA 直接存储器存取（理论） P23 [8-1]

无需 CPU 干预，自动在外设和存储器之间转运数据。

触发 → 读源地址 → 写目的地址 → 地址自增 → 计数器减1 → 到0停止(正常)/重装(循环)
  • DMA1 有 7 个通道，每个通道有固定的外设请求
  • 数据宽度：8位/16位/32位；地址可配置自增
  • 正常模式（转运一次停止）vs 循环模式（自动重装）

USART 串口通信

串口协议、外设配置、发送接收、数据包与状态机
9.1 USART 串口协议 P25 [9-1]

异步串行通信，无时钟线，双方约定波特率。

空闲(高) → 起始位(低,1位) → D0~D7(低位先行,8位) → [校验位] → 停止位(高,1位)
  • 波特率：每秒传输位数，9600 下每位约 104μs
  • 数据位低位先行（LSB first）
  • TX 与 RX 必须交叉连接，双方参数必须一致
异步起始位低位先行波特率
9.2 USART 串口外设 P26 [9-2]

STM32 USART 外设结构：波特率发生器、发送/接收数据寄存器、移位寄存器。

波特率 = fPCLK2 / (16 × DIV)，DIV 写入 BRR 寄存器
  • 发送：写 DR → TXE 置1 → 硬件逐位发送 → TC 置1
  • 接收：RX 下降沿 → 按波特率采样 → RXNE 置1 → 触发中断
BRRTXERXNETC

void USART1_IRQHandler(void)
{
    static uint8_t RxState = 0;     //状态机状态
    static uint8_t pRxPacket = 0;   //数据位置
    if (USART_GetITStatus(USART1, USART_IT_RXNE) == SET)
    {
        uint8_t RxData = USART_ReceiveData(USART1);
        if (RxState == 0) {  //等待包头FF
            if (RxData == 0xFF) { RxState = 1; pRxPacket = 0; }
        } else if (RxState == 1) {  //接收4个数据
            Serial_RxPacket[pRxPacket] = RxData;
            pRxPacket++;
            if (pRxPacket >= 4) RxState = 2;
        } else if (RxState == 2) {  //等待包尾FE
            if (RxData == 0xFE) { RxState = 0; Serial_RxFlag = 1; }
        }
        USART_ClearITPendingBit(USART1, USART_IT_RXNE);
    }
}

I2C 通信

I2C 协议、MPU6050、软件/硬件 I2C 读写
10.1 I2C 通信协议 P31 [10-1]

两根线（SCL 时钟 + SDA 数据）同步半双工通信，开漏输出 + 4.7KΩ 上拉，支持一主多从。

  • 起始 S：SCL 高电平期间 SDA 高→低
  • 终止 P：SCL 高电平期间 SDA 低→高
  • 发送字节：SCL 低放数据（高位先行），SCL 高从机读，8次
  • 应答 ACK：第9个时钟，接收方拉低 SDA
铁律：SCL 高电平期间 SDA 不允许变化，否则被误判为起始/终止。
指定地址写：S → 地址+W → ACK → 寄存器 → ACK → 数据 → ACK → P
指定地址读：S → 地址+W → ACK → 寄存器 → ACK → Sr → 地址+R → ACK → 读 → NACK → P
开漏线与高位先行ACK重复起始Sr
10.2 MPU6050 简介 P32 [10-2]

MPU6050 是 6 轴传感器：3 轴加速度 + 3 轴陀螺仪，I2C 接口，从机地址 0xD0（AD0=0）。

  • 加速度寄存器 0x3B~0x40，陀螺仪 0x43~0x48，每个轴高低 8 位
  • 电源管理 0x6B（唤醒需写0），WHO_AM_I 0x75（默认0x68）
6轴0xD00x6B唤醒WHO_AM_I
10.3 软件 I2C 读写 MPU6050（代码） P33 [10-3]

引脚配置层（PB10/PB11 开漏输出）与协议层解耦，每个时序单元结束后 SCL 都是低电平，方便拼接。

软件 I2C 起始/终止/发送字节
void MyI2C_Start(void)
{
    MyI2C_W_SDA(1);   //1.释放SDA
    MyI2C_W_SCL(1);   //2.释放SCL
    MyI2C_W_SDA(0);   //3.SCL高期间拉低SDA → 起始
    MyI2C_W_SCL(0);   //4.拉低SCL，占用总线
}

void MyI2C_SendByte(uint8_t Byte)
{
    for (uint8_t i = 0; i < 8; i++)
    {
        MyI2C_W_SDA(!!(Byte & (0x80 >> i)));  //SCL低放数据（高位先行）
        MyI2C_W_SCL(1);                        //SCL高，从机读
        MyI2C_W_SCL(0);                        //SCL低，准备下一位
    }
}
MPU6050读寄存器：Start → 0xD0 → 寄存器 → Sr → 0xD1 → 读 → NACK → Stop

    11.2 W25Q64 简介 P37 [11-2]

    W25Q64 是 64Mbit（8MB）SPI Flash 存储器，扇区 4KB，页 256 字节。

    • 写使能 0x06、页编程 0x02、扇区擦除 0x20、读数据 0x03、读状态 0x05、读ID 0x9F
    • Flash 只能把 1 写成 0，不能把 0 写成 1，写入前必须先擦除（擦后全为1）

{
    uint8_t ByteReceive = 0x00;

    12.1 Unix 时间戳 P41 [12-1]

    Unix 时间戳：从 1970-01-01 00:00:00 UTC 到现在的秒数。C 标准库 time.h 提供转换函数。

    • mktime()：年月日时分秒 → 秒计数器（需减 8 小时时区调整）
    • localtime()：秒计数器 → 年月日时分秒（需加 8 小时）

    12.2 BKP 备份寄存器 & RTC 实时时钟（理论） P42 [12-2]

    RTC 是独立定时器，VDD 掉电后由备用电池供电继续计时。LSE 外部 32.768kHz 晶振，预分频 32768-1 → 1Hz。

    • BKP_DR1~DR10：备份域寄存器，掉电保持
    • 访问备份域需先开 PWR 时钟并 PWR_BackupAccessCmd(ENABLE)
    • 用 BKP_DR1 写标志 0xA5A5 判断是否首次配置

    RTC 初始化：判断首次配置标志，首次则配置 LSE 和预分频，非首次仅等待同步。

    RTC 初始化

    RTC_WaitForLastTask();

}

    15.1 FLASH 闪存（理论） P48 [15-1]
