2.3Delay 延时函数模块P4 配套1-3 Delay.c

使用 SysTick 系统滴答定时器实现精确的微秒/毫秒/秒级延时，不占用外设定时器。

SysTick 是 24 位倒计时定时器，时钟源 HCLK=72MHz，LOAD=72×xus 即延时 xus 微秒
System/Delay.c — SysTick 寄存器操作
void Delay_us(uint32_t xus)
{
    SysTick->LOAD = 72 * xus;              //设置定时器重装值（72MHz下72个时钟=1us）
    SysTick->VAL = 0x00;                   //清空当前计数值
    SysTick->CTRL = 0x00000005;             //时钟源HCLK，启动定时器
    while(!(SysTick->CTRL & 0x00010000));   //等待计数到0（COUNTFLAG位置1）
    SysTick->CTRL = 0x00000004;             //关闭定时器
}

void Delay_ms(uint32_t xms)
{
    while(xms--) { Delay_us(1000); }
}

3.1GPIO 输出P5 [3-1]

GPIO 通用输入输出端口，8 种工作模式：

  • 推挽输出：P-MOS+N-MOS 都工作，高低电平都有强驱动（LED、蜂鸣器）
  • 开漏输出：只有 N-MOS，高电平为高阻态，需外部上拉（I2C）
  • 复用推挽/开漏：由外设控制引脚（TX、PWM、硬件I2C）
  • 上拉/下拉/浮空输入：按键、RX 等；模拟输入：ADC 采集
推挽输出：写1→P-MOS导通→强高电平；写0→N-MOS导通→强低电平

void OLED_I2C_SendByte(uint8_t Byte)
{

中断原理、NVIC 优先级、EXTI 外部中断及两个实验
5.1EXTI 外部中断P11 [5-1]

中断让 CPU 暂停当前任务，优先处理紧急事件。

主程序 → 中断触发 → 保存断点 → 中断服务函数 → 恢复断点 → 继续主程序
  • NVIC 优先级：抢占优先级（可嵌套）+ 响应优先级（排队不可嵌套），分组2：2位抢占+2位响应
  • EXTI 线路：引脚电平变化 → AFIO 选择引脚 → EXTI 边沿检测 → NVIC → 中断服务函数
  • 相同 Pin 号不能同时挂中断（PA0 和 PB0 不能同时用 EXTI0）
进入中断后必须清除中断标志位，否则反复进入中断导致主程序卡死。中断函数名必须与启动文件向量表一致。

6.1TIM 定时中断（理论）P13 [6-1]

定时器时基单元：PSC 预分频器 + CNT 计数器 + ARR 自动重装器。

CK_PSC(72MHz) → [PSC+1分频] → CK_CNT → [CNT计数] → 达到ARR → 更新事件 → 中断
溢出时间 T = (PSC+1) × (ARR+1) / 72000000 秒
  • PSC=7199, ARR=9999 → T = 7200×10000/72MHz = 1秒
  • APB1 定时器时钟经倍频后为 72MHz（APB1 预分频≠1 时×2）
TIM_TimeBaseInit() 末尾会手动产生一次更新事件，开中断前必须先 TIM_ClearFlag()。
PSCCNTARR更新事件影子寄存器
6.2定时器定时中断（代码）P14 [6-2]6-1 Timer.c

System/Timer.c — 定时中断初始化
void Timer_Init(void)
{
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    TIM_InternalClockConfig(TIM2);              //选择内部时钟

    TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInitStructure.TIM_Period = 10000 - 1;       //ARR → 1秒
    TIM_TimeBaseInitStructure.TIM_Prescaler = 7200 - 1;     //PSC
    TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

    TIM_ClearFlag(TIM2, TIM_FLAG_Update);        //关键！清除初始化产生的更新标志
    TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM2, ENABLE);                    //启动定时器
}

    static uint8_t pRxPacket = 0;
    if (USART_GetITStatus(USART1, USART_IT_RXNE) == SET)
    {
        uint8_t RxData = USART_ReceiveData(USART1);
        if (RxState == 0) {            //状态0：等包头FF
            if (RxData == 0xFF) { RxState = 1; pRxPacket = 0; }
        } else if (RxState == 1) {     //状态1：收4个数据
            Serial_RxPacket[pRxPacket] = RxData;
            pRxPacket++;
            if (pRxPacket >= 4) RxState = 2;
        } else if (RxState == 2) {     //状态2：等包尾FE
            if (RxData == 0xFE) { RxState = 0; Serial_RxFlag = 1; }
        }
        USART_ClearITPendingBit(USART1, USART_IT_RXNE);
    }

{
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_PWR | RCC_APB1Periph_BKP, ENABLE);
    PWR_BackupAccessCmd(ENABLE);

    if (BKP_ReadBackupRegister(BKP_DR1) != 0xA5A5)  //首次上电
    {
        RCC_LSEConfig(RCC_LSE_ON);
        while (RCC_GetFlagStatus(RCC_FLAG_LSERDY) == RESET);  //等32.768kHz起振
        RCC_RTCCLKConfig(RCC_RTCCLKSource_LSE);
        RCC_RTCCLKCmd(ENABLE);
        RTC_WaitForSynchro();
        RTC_WaitForLastTask();
        RTC_SetPrescaler(32768 - 1);  //32768Hz → 1Hz
        RTC_WaitForLastTask();
        MyRTC_SetTime(2026, 8, 23, 16, 0, 0);
        BKP_WriteBackupRegister(BKP_DR1, 0xA5A5);  //写标志
    }
    else  //非首次：仅同步
    {
        RTC_WaitForSynchro();
        RTC_WaitForLastTask();
    }
}

13.1PWR 电源控制（理论）P44 [13-1]

STM32 三种低功耗模式对比：

  • 睡眠模式 Sleep：CPU 停，外设运行，任何中断唤醒，唤醒后继续执行
  • 停止模式 Stop：所有时钟停，寄存器/SRAM 保持，外部中断唤醒，唤醒后需重配时钟
  • 待机模式 Standby：全部断电，仅备份域/WKUP 保持，WKUP 引脚或 RTC 闹钟唤醒，唤醒后复位重启

WDG 看门狗

独立看门狗 IWDG 与窗口看门狗 WWDG，防止程序跑飞
14.1看门狗（理论）P46 [14-1]

看门狗本质是定时器，超时未喂狗则复位芯片。

  • IWDG 独立看门狗：LSI(40kHz) 独立时钟，主时钟故障仍可工作，超时时间固定上限
  • WWDG 窗口看门狗：APB1 时钟，必须在"窗口"内喂狗——太早也复位、太晚也复位
IWDG超时 = (4×2^PR) × (RLR+1) / 40000 秒；WWDG窗口值 < 喂狗值 < 0x7F
IWDGWWDG喂狗LSI 40kHz窗口
14.2独立看门狗 IWDGP47 [14-2]14-1 main.c

预分频 16、重装值 2499 → 超时约 1 秒。按键阻塞模拟卡死，正常循环中喂狗。先查 RCC_FLAG_IWDGRST 判断上次是否看门狗复位。

User/main.c — IWDG 配置与喂狗
// 判断复位来源
if (RCC_GetFlagStatus(RCC_FLAG_IWDGRST) == SET) {
    OLED_ShowString(1, 1, "IWDG RST!");
    RCC_ClearFlag();
}

// IWDG配置：超时≈1秒
IWDG_WriteAccessCmd(IWDG_WriteAccess_Enable);  //解除写保护
IWDG_SetPrescaler(IWDG_Prescaler_16);         //40k/16=2.5kHz
IWDG_SetReload(2499);                          //2.5k/2500=1秒
IWDG_ReloadCounter();                           //先喂一次狗
IWDG_Enable();                                  //启动（一旦启动无法关闭）

while (1) {
    IWDG_ReloadCounter();  //喂狗
    if (Key_GetNum() == 1) {
        Delay_ms(5000);   //模拟卡死5秒 → 看门狗复位
    }
    Delay_ms(500);       //正常循环，每500ms喂一次
}

FLASH 闪存

读写内部 Flash 做掉电存储，以及读取芯片唯一 ID
15.1FLASH 闪存（理论）P48 [15-1]

STM32F103C8T6 有 64KB 主 Flash（每页 1KB），用于存储程序和常量。可在运行时擦写，但必须先擦除再写入。

  • 擦除：最小单位为页（1KB），擦除后全为 0xFF
  • 写入：支持 16 位半字编程，写入前必须 Unlock
  • 操作流程：解锁 → 擦除页 → 编程数据 → 上锁
  • 读取：直接用指针解引用地址即可
最后一页（0x0800FC00）通常不被程序占用，可安全用于数据存储。写 Flash 期间 CPU 暂停。
64KB页1KB擦除→写入Unlock/Lock16位编程
15.2读写内部 FlashP49 [15-2]15-1 MyFLASH.c / Store.c

MyFLASH.c 封装底层读写擦除，Store.c 实现带标志位的 512 半字数组掉电存储：SRAM 镜像 + 初始化加载 + 保存时擦写整页。

System/MyFLASH.c — 底层操作
// 读32位字
uint32_t MyFLASH_ReadWord(uint32_t Address) {
    return *(__IO uint32_t *)Address;
}
// 读16位半字
uint16_t MyFLASH_ReadHalfWord(uint32_t Address) {
    return *(__IO uint16_t *)Address;
}

// 擦除一页：Unlock → ErasePage → Lock
void MyFLASH_ErasePage(uint32_t PageAddress) {
    FLASH_Unlock();
    FLASH_ErasePage(PageAddress);
    FLASH_Lock();
}

// 编程16位半字：Unlock → ProgramHalfWord → Lock
void MyFLASH_ProgramHalfWord(uint32_t Address, uint16_t Data) {
    FLASH_Unlock();
    FLASH_ProgramHalfWord(Address, Data);
    FLASH_Lock();
}
Hardware/Store.c — 掉电存储管理
#define STORE_START_ADDRESS  0x0800FC00
#define STORE_COUNT          512
uint16_t Store_Data[STORE_COUNT];  //SRAM镜像数组

// 初始化：检查0xA5A5标志，有效则加载Flash到SRAM；无效则擦除并初始化
void Store_Init(void) {
    if (MyFLASH_ReadHalfWord(STORE_START_ADDRESS) != 0xA5A5) {
        MyFLASH_ErasePage(STORE_START_ADDRESS);
        MyFLASH_ProgramHalfWord(STORE_START_ADDRESS, 0xA5A5);  //写有效标志
        for (i=1; i<STORE_COUNT; i++)
            MyFLASH_ProgramHalfWord(STORE_START_ADDRESS+i*2, 0);
    }
    for (i=0; i<STORE_COUNT; i++)
        Store_Data[i] = MyFLASH_ReadHalfWord(STORE_START_ADDRESS+i*2);
}

// 保存：擦除整页后把SRAM数组全部编程到Flash
void Store_Save(void) {
    MyFLASH_ErasePage(STORE_START_ADDRESS);
    for (i=0; i<STORE_COUNT; i++)
        MyFLASH_ProgramHalfWord(STORE_START_ADDRESS+i*2, Store_Data[i]);
}
