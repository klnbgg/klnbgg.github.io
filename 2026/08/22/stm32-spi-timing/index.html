9 SPI通信时序——重点

9.1 物理层

作用：用四根线实现同步全双工高速通信。

信号线 作用
SCK 时钟线，主机产生
MOSI 主出从入（主机发送）
MISO 主入从出（主机接收）
SS 片选，低电平有效

9.2 时序基本单元

  • 起始：SS从高拉低
  • 终止：SS从低拉高
  • 交换一个字节：SCK产生8个脉冲，每个脉冲同时移出1位（MOSI）、移入1位（MISO），高位先行

9.3 四种模式（CPOL/CPHA）

模式 CPOL CPHA SCK空闲 采样边沿 移出边沿
0 0 0 低 上升沿（第1个边沿） 下降沿（第2个边沿）
1 0 1 低 下降沿（第2个边沿） 上升沿（第1个边沿）
2 1 0 高 下降沿（第1个边沿） 上升沿（第2个边沿）
3 1 1 高 上升沿（第2个边沿） 下降沿（第1个边沿）

解释：

  • CPOL（时钟极性）：决定SCK空闲电平
  • CPHA（时钟相位）：决定第几个边沿采样数据

9.4 W25Q64 Flash操作时序要点

  1. 写使能（0x06）：每次写入/擦除前必须执行
  2. 页编程（0x02）：24位地址+数据，最多256字节，不能跨页
  3. 扇区擦除（0x20）：擦除4KB，擦后全为1
  4. 读数据（0x03）：24位地址后连续读取
  5. 写入前必须先擦除（Flash只能把1写成0，不能把0写成1）
  6. 写完需轮询状态寄存器忙标志位（bit0）
