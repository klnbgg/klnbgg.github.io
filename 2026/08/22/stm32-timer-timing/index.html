6 定时器时序（TIM）——核心重点

6.1 时基单元

作用：定时器最核心的功能，通过计数实现精确的时间基准。

组成：PSC预分频器 + CNT计数器 + ARR自动重装器

关键公式：

  • 计数器频率：CK_CNT = CK_PSC / (PSC + 1)
  • 溢出时间：T = (PSC + 1) × (ARR + 1) / 72000000 秒

示例：PSC=7199, ARR=9999 → T = 7200×10000/72MHz = 1秒

6.2 时基单元时序细节

  1. PSC影子寄存器：写入新的PSC值后不会立即生效，要等下一次更新事件才生效
  2. ARR预装（ARPE位）：
    • ARPE=0：写入ARR立即生效，当前周期可能被截断
    • ARPE=1：写入ARR后等更新事件才生效，周期完整
  3. 初始化陷阱：TIM_TimeBaseInit() 末尾会手动产生一次更新事件，所以开中断前必须先 TIM_ClearFlag()，否则会立即进一次中断

6.3 PWM输出时序

作用：输出占空比可调的方波信号，用于控制LED亮度、舵机角度、电机转速。

PWM波形：

参数公式：

  • PWM频率：Freq = CK_PSC / (PSC+1) / (ARR+1)
  • 占空比：Duty = CCR / (ARR+1)
  • 分辨率：Reso = 1/(ARR+1)

PWM模式1：CNT<CCR时输出有效电平，CNT≥CCR时输出无效电平。

舵机控制时序（重点）：

  • 周期20ms（50Hz）
  • 高电平宽度：0.5ms→-90°，1.5ms→0°，2.5ms→+90°
  • 配置：PSC=720-1, ARR=2000-1 → CCR=50~250

6.4 输入捕获测频率时序（测周法）

作用：测量外部信号的频率。

时序流程：

配置要点：

  • PSC=72-1 → fc=1MHz，频率 = 1000000/(CCR1+1)
  • ARR=65536-1（最大量程）
  • 滤波器 TIM_ICFilter=0xF 过滤信号抖动
  • 从模式Reset：每个上升沿自动清零CNT

6.5 PWMI模式测频率和占空比

作用：同时测量频率和占空比。

  • 通道1直连：上升沿捕获CCR1 = 周期
  • 通道2间接：下降沿捕获CCR2 = 高电平时间
  • 频率 = fc/CCR1，占空比 = CCR2/CCR1

6.6 编码器接口时序

作用：硬件自动解析正交编码器的方向和位移，无需CPU干预。

正交编码时序：

  • TIM_EncoderMode_TI12：两相都计数，4倍频精度
  • 每隔固定时间（定时中断）读CNT增量并清零，即为速度
