1 时序基础

1.1 什么是时序

作用：时序就是电信号随时间变化的波形，单片机通过引脚输出高低电平的组合与时间关系，与外设”对话”。

两种时序类型：

  1. 同步时序：有一根独立的时钟线（SCL/SCK），双方按时钟节拍收发数据
    • 典型协议：I2C、SPI
  2. 异步时序：没有时钟线，双方约定波特率，靠起始位/停止位同步
    • 典型协议：USART

基本概念：

  • 电平有效：高电平或低电平代表有效信号
  • 边沿触发：上升沿（低→高）或下降沿（高→低）触发动作
  • 高位先行/低位先行：数据位的发送顺序

1.2 单片机为什么需要时序

  • 外设（OLED、MPU6050、W25Q64等）不是任意时刻都能读写，必须在指定的时钟节拍操作
  • 时序错误会导致通信失败、数据错乱甚至外设死锁
  • 软件模拟时序时，延时精度直接决定通信可靠性

2.2 时钟源对比

时钟源 频率 精度 用途
HSI 8MHz 低（1%误差） 内部RC，上电默认使用
HSE 8MHz 高（20ppm） 外部晶振，PLL锁相环来源
LSI 40kHz 低 独立看门狗IWDG
LSE 32.768kHz 高 RTC实时时钟，备用电池供电

2.3 关键注意事项

  1. 所有外设在使用前必须开启对应总线时钟，否则寄存器读写无效——这是STM32与51单片机最大的区别
  2. APB1最大36MHz，但定时器时钟经倍频后仍为72MHz
  3. ADCCLK最大14MHz，必须通过分频确保不超限
  4. SystemInit() 在main函数之前自动执行，不需要手动调用

3 SysTick延时时序

3.1 SysTick定时器

作用：Cortex-M3内核自带的24位倒计时定时器，用于实现精确延时。

工作流程：

  1. 写入重装值LOAD
  2. 清空当前值VAL
  3. 启动定时器（CTRL=5：时钟源HCLK+使能）
  4. 等待COUNTFLAG位（bit16）置1，表示计数到0
  5. 关闭定时器

3.2 代码实现

文件：System/Delay.c

解释：

  • LOAD = 72 * xus：72MHz主频下，计数72次为1μs
  • CTRL = 0x05：bit0=1（使能），bit1=0（不中断），bit2=1（HCLK时钟源）
  • bit16 COUNTFLAG：计数到0时硬件置1，读取后自动清零
  • Delay_ms和Delay_s通过循环调用Delay_us实现

注意：xus范围0~233015（24位最大值/72）。
