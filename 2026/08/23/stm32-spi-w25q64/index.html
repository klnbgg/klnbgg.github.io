  • 默认：SS=1（不选中），SCK=0（模式0空闲低电平）

30.3 W25Q64操作函数

文件：Hardware/W25Q64.c

读ID：Start → 0x9F → 读MID → 读DID高 → 读DID低 → Stop

写使能：Start → 0x06 → Stop（每次写入/擦除前必须调用）

页编程：

扇区擦除：写使能 → Start → 0x20 → 24位地址 → Stop → 等待忙

读数据：Start → 0x03 → 24位地址 → 连续读 → Stop

等待忙：Start → 0x05 → 循环读状态寄存器直到bit0=0（带超时保护）→ Stop

注意：写入前必须先擦除（擦后全为1）；Flash只能把1写成0，不能把0写成1。
