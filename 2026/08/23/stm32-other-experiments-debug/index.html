34 常见问题与调试技巧

34.1 时序调试

  1. 示波器/逻辑分析仪是验证时序的最佳工具
  2. 软件模拟时序时 Delay_us() 精度决定通信可靠性
  3. I2C/SPI通信失败排查顺序：接线 → 引脚模式（I2C必须开漏）→ 时序延时 → 从机地址

34.2 中断注意事项

  1. 中断服务函数尽量短，只设标志位，主循环中处理
  2. 中断中不能使用阻塞式延时
  3. 多个中断共享一个通道时（如EXTI15_10），必须判断具体是哪个中断线
  4. NVIC分组整个工程只能配置一次

34.3 代码编写规范

  1. 每个硬件模块封装为独立的 .c/.h 文件，放在Hardware目录
  2. .h 文件用 #ifndef/#define/#endif 防止重复包含
  3. 初始化函数注释按 /*第一步*/、/*第二步*/ 分段
  4. 全局变量少用，需要跨文件访问时在 .h 中用 extern 声明
